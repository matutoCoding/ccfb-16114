# 胎面节距设计与接地分析系统（Tread Studio）

面向花纹设计组的纯前端工作台：在开模之前，于浏览器内完成节距排列降噪设计、接地印痕/海陆比/排水分析与转鼓数据比对，避免"改一次模具两个月、几十万"的试错成本。

- **技术栈**：TypeScript（strict）+ WebGPU（compute shader）+ Vite，零重型运行时框架
- **持久化**：花纹单元、节距序列、项目、转鼓试验记录与压力纸扫描图全部存 IndexedDB
- **双后端**：WebGPU 并行深度场（交互/滚动）+ CPU 条带解析积分（精度基准与无 GPU 降级）

## 启动

```bash
npm install
npm run dev        # 开发服务器
npm test           # Vitest：23 个用例，含海陆比 0.5% 红线
npm run build      # 类型检查 + 生产构建（gzip 约 24KB JS）
```

## 两条硬指标如何保证

### 1. 海陆比误差 ≤ 0.5%（规则矩形花纹块对几何手算）

面积统计**不靠栅格赌误差**，而用 y 向条带解析积分：

- 每条带接地半长 `a(y)=sqrt(2R(δ-c(y)))` 由压扁模型解析给出；
- 纵沟在条带内做区间精确求交（并集长度），矩形沟的常值占比在比值中对消；
- 横沟/刀槽沿 x 采样计入并扣除纵沟重叠；
- 网格深度场仅用于可视化与体积积分。

见 `tests/footprint.test.ts`：单沟、四纵沟两组规则矩形块，海陆比与独立手算实现相对误差断言 `≤0.005`；另含光面胎海陆比为 0、网格/积分面积随分辨率收敛等用例。

### 2. 整胎一万多个花纹块滚动 ≥ 50 FPS

- WebGPU compute shader 逐格点并行算深度场，节距定位用 **O(log n) 二分**（与万块序列解耦）；
- 滚动播放只跑 GPU 深度场，CPU 精确统计仅在暂停/出报告时执行；
- 接地页"万块压力测试"按钮实测：本机 10240 块、320×160 网格、30 帧，**纯 GPU 约 5.4ms/帧 ≈ 185 FPS**（实时滚动约 130 FPS），远超 50 FPS 验收线。无 WebGPU 时自动回退 CPU。

## 工程模型说明

- 压扁几何：胎冠抛物线 `c(y)=k·y²`，滚筒弧近似下接地半长 `a(y)=sqrt(2R(δ-c(y)))`，二分下沉量 δ 使接地面积满足 `A=F/p`。
- 花纹沟剖面：沟口宽含倒角、沟底按沟壁角收窄，深度随到沟心距离线性衰减；横沟/刀槽为倾斜线段并做三周期延拓保证接缝连通。
- 阶次谱：对节距长度序列去均值后零填充 DFT，阶次为每转周期数，频率 = 阶次 × 转动频率；等节距零方差序列按 100% 能量集中的纯音处理。
- 所有物理量单位：mm、N、kPa、Hz、mm²、mm³。
